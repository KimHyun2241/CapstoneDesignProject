## 손동작 인식 및 객체 탐지를 적용한 애완봇
### 프로젝트 개요
- 이 프로젝트는 손동작 인식과 객체 탐지 기술을 활용하여 사용자와 상호작용할 수 있는 IoT 기반 애완봇을 제작하는 데 목적
- 라즈베리파이 5를 기반으로 DC 모터, 초음파 센서, MQTT 프로토콜, Mediapipe 및 Simple RNN 모델을 활용하여 애완봇이 환경과 사용자와 상호작용하는 지능형 동작을 수행하도록 설계

## 기능 및 특징
1. 손동작 인식 및 객체 탐지
- Mediapipe를 활용하여 사용자의 손동작을 인식하고, 객체 탐지로 애완봇이 환경을 인식.
- 간단한 손동작으로 애완봇을 제어하거나 명령 수행 가능.

2. 손동작 전달을 위한 통신
- MQTT 프로토콜을 사용하여 실시간 손동작 전달

3. 지능형 행동
- Simple RNN 모델을 통해 학습된 패턴에 따라 사용자의 의도를 파악하고 동작 수행.
- DC 모터와 초음파 센서를 이용해 장애물을 탐지하고 회피.

4. 프로토타입 제작
- 3D 모델링 및 3D 프린팅 기술로 애완봇 하드웨어 제작.

## 사용 기술 및 하드웨어

### 소프트웨어
Python: 주요 프로그램 언어로 데이터 처리 및 모델 구현.
Mediapipe: 손동작 인식 및 객체 탐지.
Simple RNN: 손동작 신호 패턴 분석 및 학습.
MQTT: IoT 통신 프로토콜로 실시간 데이터 송수신.

### 하드웨어
라즈베리파이 5: 애완봇의 중앙 컨트롤러.
DC 모터: 애완봇의 이동 동작 제어.
초음파 센서: 장애물 탐지 및 회피.
3D 프린팅 및 모델링: 애완봇 외형 제작.
